# 📱 LawSaathi – AI-Powered Legal Mobile Application

**LawSaathi** is an AI-driven mobile application designed to provide real-time legal assistance through text and voice interfaces. It helps citizens and frontline law enforcement officers access multilingual legal guidance powered by a custom-trained Indian legal LLM, especially in areas where legal help is not readily available.

---

## 🚀 Features

* 🔐 **Firebase Authentication** – Secure user registration and login.
* 💬 **AI Chatbot** – Text-based legal query resolution using an Indian law–trained LLM.
* 😥️ **AI Voice Assistant** – Real-time voice-based legal consultation via Bland.ai.
* 🌐 **Multilingual Support** – Available in English, Hindi, Tamil, Bengali, Kannada, and Marathi.
* 📟 **Chat & Call History Logs** – Review past legal conversations anytime.
* 🔔 **Push Notifications** – Receive timely legal updates and reminders.
* 📱 **Cross-platform** – Developed using Flutter with Firebase backend.

## 📦 Installation

1. **Clone the repo**

   ```bash
   git clone https://github.com/yourusername/LawSaathi.git
   cd LawSaathi
   ```

2. **Install dependencies**

   ```bash
   flutter pub get
   ```

3. **Run the app**

   ```bash
   flutter run
   ```

> Make sure your Firebase project is set up and `google-services.json` / `GoogleService-Info.plist` is configured correctly.
